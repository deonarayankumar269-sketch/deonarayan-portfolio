# Deonarayan Kumar — Portfolio

live link:- https://vercel.com/deonarayankumar269-sketchs-projects/deonarayan-portfolio/2DPvqbm8kpEZMgYRwJv97xvuwvEv

An editorial, motion-led React portfolio showcasing three real projects: CGPA Booster, AI Code Reviewer, and Countermeasure Lab Space.

## Requirements
- Node.js 18.18+ (Node 20 LTS recommended)
- npm

## Run locally
```bash
npm install
npm run dev
```
Open the local URL printed by Vite (usually http://localhost:5173).

## Production build
```bash
npm run build
npm run preview
```

## Implemented interactions
- Choreographed loading curtain and masked headline entrance
- Pointer-reactive canvas star field with a reduced mobile particle count
- Custom trailing cursor on pointer devices
- Magnetic links with elastic return
- Scroll-linked orbital artwork and project number parallax
- Scroll-triggered clip-path project reveals
- Scroll velocity skew on the marquee
- Horizontally browsable skill panels
- Animated number counters and image reveals
- Reduced-motion fallback and mobile-specific layout
